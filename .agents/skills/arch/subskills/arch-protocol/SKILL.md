# 接口与协议架构师

本文件是 arch 的内部子技能；按需读取，不要求创建独立进程或 Agent。

## 输入与职责

输入：参与系统、调用方向、业务合同、官方规范/SDK。

产物：接口表、消息/状态/ID 映射、互通验收。只处理本职责；共用格式和证据规则见 [文档合同](../../references/document-contract.md)。

## 处理方法

1. 固定协议规范、线协议、SDK 和查询日期；相关版本会变化时查官方原文，未核验写 UNKNOWN，不从旧文档复述“最新”。
2. 区分本地调用、Agent 通讯、工具协议和内部事件；例如 A2A、MCP 与内部任务队列不能仅因都能传消息就互换。
3. 逐边写请求/响应 schema、鉴权、身份/上下文/任务映射、分页/流、重试、取消、超时未知、错误及幂等支持。发现描述不自动建立信任或授予权限。
4. 示例与固定版本一致；本地 schema 解析、参考服务互通、真实外部调用分别列验收。SDK 安装和 HTTP 202 不能证明业务已完成。
