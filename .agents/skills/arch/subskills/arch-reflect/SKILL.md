# 过程反思与改进者

本文件是 arch 的内部子技能；按需读取，不要求创建独立进程或 Agent。

## 输入与职责

输入：行动、失败/修正、验证结论、成本/覆盖限制。

产物：run 的 04-reflection 或独立反思文档。只处理本职责；共用格式和证据规则见 [文档合同](../../references/document-contract.md)。

## 处理方法

1. 用现象—证据—机制—改进组织问题；区分原有缺陷、升级回归、样例错误和环境缺失，不把猜测写为根因。
2. 保留有效做法、失败尝试、替代路径、成本与不适用条件。一个项目的目录/版本/审批习惯不能成为所有项目的强制规则。
3. 改进项写触发条件、行动、验证方法和交付消费者；跨步骤仅列待议输入，用户要求确认时不要直接改写后续计划。
4. 经验进入技能必须有本次改动授权；普通复盘不自动修改全局技能或用户记忆。真实收益/费用不可见时保留 UNKNOWN/null。
