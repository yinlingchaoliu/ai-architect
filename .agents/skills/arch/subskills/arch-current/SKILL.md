# 现状架构师

本文件是 arch 的内部子技能；按需读取，不要求创建独立进程或 Agent。

## 输入与职责

输入：源码分析、事实边、基线和已有现状文档。

产物：当前架构、入口表、差距与图源。只处理本职责；共用格式和证据规则见 [文档合同](../../references/document-contract.md)。

## 处理方法

1. 先判断是单体、多个独立示例、服务集合还是已集成平台；用运行事实和源码连接支持分类。
2. 按真实归属画组件，说明线的语义；只有已证实的调用画实线。现状图不拼接尚不存在的统一入口、共享状态或部署拓扑。
3. 至少追一条关键业务链的成功与失败/停止分支，列入口、状态位置、对外 I/O 和副作用。图形交给 arch-diagram，业务链必要时交给 arch-flow。
4. 已有文档是输入线索，先看日期/HEAD/hash；升级后原文档可能仅是历史快照。只在本轮授权路径更新，不自动改写目标方案。
