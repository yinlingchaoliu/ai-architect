# 源码分析师

本文件是 arch 的内部子技能；按需读取，不要求创建独立进程或 Agent。

## 输入与职责

输入：源码目录、入口、配置声明与允许读取范围。

产物：源码分析、模块/边事实、选取文件指纹。只处理本职责；共用格式和证据规则见 [文档合同](../../references/document-contract.md)。

## 处理方法

1. 先用文件列表和定向搜索找入口、装配、依赖和测试，再沿一条实际输入追到输出与错误/停止。目录名、README 愿景和类存在不自动成为已接入事实。
2. 对重要调用边记录调用方、被调方、符号/行号、条件与来源；区分定义、启动装配、进程内注册、跨进程通信与部署。
3. 分别看依赖声明、锁、解释器、已安装版本。没有启动就标静态观察；空文件、未消费配置、模拟工具、旁路接口和失败仍完成等差异明确列出。
4. 只为实际选取的文件生成快照；hash_only 不等于逐行已读。源码变更或旧 snapshot 漂移后重新读取受影响文件，不能复用过期关系。
