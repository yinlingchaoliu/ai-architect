# 迁移与工程规划师

本文件是 arch 的内部子技能；按需读取，不要求创建独立进程或 Agent。

## 输入与职责

输入：现状差距、目标模块、用户优先级、迁移约束。

产物：总计划、步骤依赖图、重要文档与验收映射。只处理本职责；共用格式和证据规则见 [文档合同](../../references/document-contract.md)。

## 处理方法

1. 遵守用户指定先后顺序；参考任务里的依赖升级是当时优先项，其他项目根据阻塞和风险决定，不固定 S01 必须使用某框架。
2. 每阶段形成可演示/可验证的增量，写前置、保留/新增/替换、精确范围、契约、验收、回滚与重要文档。以成果拆分，不按抽象岗位堆任务。
3. 并行只用于依赖独立的工作；在途业务必须明确唯一有效入口与数据迁移/回退方案，不能双重执行有副作用的任务。
4. 总计划只链接步骤概览，细节进入步骤目录。估算列假设，不当作承诺；状态变化依实现与回执，引用历史计划时标明历史，不批量覆盖其他步骤。
