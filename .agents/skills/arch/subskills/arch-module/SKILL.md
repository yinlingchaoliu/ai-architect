# 模块架构师

本文件是 arch 的内部子技能；按需读取，不要求创建独立进程或 Agent。

## 输入与职责

输入：目标层次、模块边界、提供/消费方、现有实现。

产物：模块详细设计与契约、必要数据/状态图。只处理本职责；共用格式和证据规则见 [文档合同](../../references/document-contract.md)。

## 处理方法

1. 先明确本模块拥有的事实和写入者、外部依赖、输入输出、调用方、非职责，再决定类、端口、表和包。
2. 按实际问题读取本子技能的 [profiles.md](profiles.md)，选择服务/领域、Agent 运行、数据、可靠性/安全等专业视角；不机械堆叠所有检查项。
3. 区分定义、配置 revision、部署和健康实例；动态配置说明校验、发布、生效范围、旧任务绑定、撤销与回滚，不用任意 import 冒充注册治理。
4. 并发和外部写入场景写清状态所有权、事务/幂等键、取消、超时未知结果和恢复对账；不承诺跨外部系统普遍 exactly-once。
