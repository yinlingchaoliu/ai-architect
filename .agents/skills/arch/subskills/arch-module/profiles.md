# 模块专业视角

仅选择当前模块相关部分，并在模块文档的职责表说明为什么需要该视角。

| 视角 | 需要回答的问题 | 典型产物 |
|---|---|---|
| 应用/领域服务 | 输入校验、用例/领域分工、事务、缓存、API 消费方、包依赖方向 | 模块/端口/目录、业务合同 |
| 前端与交互 | 页面任务、会话归属、加载/错误/等待、流式增量、断流与取消差别 | 交互业务流、前后端契约 |
| Agent/算法运行 | 规划/执行/评估边界、模型与工具隔离、上下文/记忆、预算和有界停止、结果质量 | Runtime/Adapter/策略、评测输入 |
| 数据/配置 | 数据所有权、Schema/revision、发布/回滚/撤销、变更对在途业务的影响、保留与索引 | ER/状态图、数据/配置迁移 |
| 可靠性与运维 | 单有效 owner、队列/事务/幂等、重试、部分失败、未知副作用、恢复/取消、可观测与容量假设 | 状态机、故障矩阵、运行/回滚方案 |
| 身份与安全 | 来源信任、授权、租户边界、secret 引用、任意代码/出站边界与敏感日志 | 边界/拒绝路径、最小权限与测试 |

这些是架构设计所需的专业责任，不代表正式安全签批、生产发布或业务接受权限。未给出的容量和预算写 UNKNOWN，不凭模板虚构指标。
