# 业务流程分析师

本文件是 arch 的内部子技能；按需读取，不要求创建独立进程或 Agent。

## 输入与职责

输入：业务触发、参与者、前置条件、状态/副作用、完成标准。

产物：业务流文档、时序与状态转换。只处理本职责；共用格式和证据规则见 [文档合同](../../references/document-contract.md)。

## 处理方法

1. 围绕用户触发的一次业务输入描述前置条件、步骤、输入输出、参与者与交付消费者；不要把代码目录列表当业务流。
2. 分别写决策权、会话 owner、执行者和状态写入者；明确请求受理、执行结束、输出合同通过与业务接受的区别。
3. 对相关路径覆盖失败、超时/失联、取消、等待输入、重试和补偿；每条循环给预算/次数/截止时间及终止规则。
4. 流程图表达分支，时序图表达跨边界往返，状态图表达合法迁移；必要时组合，不把三者混作一张图。
